BankProject
A Java project. It's a simple banking program that runs in the console. I made it while learning Java, following a YouTube tutorial and fixing a lot of my own mistakes along the way.
What it does?
You get a menu with 4 options:
Show balance
Deposit
Withdraw
Exit
It keeps going back to the menu until you pick 4. You can't deposit a negative amount, and you can't withdraw more than you have. After a withdrawal it shows how much is left.

How to run it
Download or clone this repo
Open the folder in IntelliJ (or any Java IDE)
Open src/Main.java and press the green run button

If you type a letter instead of a number, it crashes. Still working on that.
